# 2탄 컨셉 — 포포의 사계절 서울 (2026-11-04, 승인됨)

> 사용자 지시: "2탄은 귀여운 아기 강아지가 봄·여름·가을·겨울의 서울을 여행하는 컨셉으로, 나머지는 1탄과 같은 내용으로"
> 사용자 답: **같은 게임 안에** / **계절 옷이 바뀜** / **계절마다 1단계 = 4단계** / 이름 **블루나비 친구 '포포'**

## 한눈에
- 제목: **포포의 사계절 서울** (작게 "블루나비의 세계여행 2탄")
- 주인공: **포포** — 하얀 털에 귀 끝만 연한 갈색인 아기 강아지. 둥근 몸, 큰 눈, 볼터치, 짧은 꼬리 (1탄 그림체 그대로).
- 안내 친구: **블루나비** (1탄 주인공이 도트처럼 옆에서 "포포야, 이쪽!" 하고 도와준다)
- 판단 기준: "귀엽고 친근한가?", "내 동네도 계절마다 새로운 여행지가 된다는 느낌인가?"
- 같은 링크(blue-naby-game.web.app) 타이틀에서 **[1탄 블루나비] / [2탄 포포]** 고르기. 저장은 1탄과 따로(2탄 칸), 저장 코드·둘이서 하기·각자 폰 대결·기념품 퐁퐁·기록 카드는 1탄과 같은 방식.

## 이야기
- 프롤로그: 서울 어느 골목 집 마당, 아기 강아지 포포. 세계여행을 마친 블루나비가 날아와 여행 이야기를 들려준다. "멀리 안 가도 돼. 네가 사는 서울도 계절마다 완전히 다른 나라 같아!" → 포포의 사계절 서울 여행 시작.
- 단계마다: 미로 → 심술 난 친구와 놀아 주기(대결) → 친구가 됨 → **계절 옷 선물** → '옷 갈아입기' 장면(1탄 진화 자리) → 다음 계절.
- 엔딩: 다시 돌아온 봄날 마당. 포포가 사계절 옷을 모두 걸어 둔 앨범을 펼치고, 친구들과 블루나비가 모두 모인다. "블루나비의 세계여행 2탄 — 포포의 사계절 서울 — 끝"

## 4단계 (계절마다 1단계)
| 단계 | 계절 · 서울 무대 | 수집품 | 방해 요소 (**단계마다 최대 2가지**) | 친구(보스) → 선물 |
|---|---|---|---|---|
| 1 | 봄 · 한강 벚꽃길(여의도)과 고궁 돌담 | 개나리꽃 6 | 자전거(순찰), 움직이는 봄비 웅덩이(퐁) | 까치 **깍깍이** → 꽃 모자 |
| 2 | 여름 · 한강 물놀이장과 청계천 징검다리 | 수박 조각 7 | 물총 놀이(순찰), 움직이는 소나기 웅덩이(퐁) | 청개구리 **개굴이** → 물놀이 튜브 |
| 3 | 가을 · 남산 은행나무길과 돌담길 | 은행잎 7 | 굴러오는 밤송이(순찰), 낙엽 회오리(바람에 밀림) | 고슴도치 **밤톨이** → 줄무늬 목도리 |
| 4 | 겨울 · 광화문 눈 광장과 북촌 한옥 골목 | 눈송이 8 | 눈썰매(순찰), 미끄러운 얼음(바람처럼 미끄러짐) | 눈사람 **뭉치** → 털모자, 그리고 아기 곰 **곰실이** (대결 2번) |
| 엔딩 | 다시 봄, 포포네 마당 · 사계절 앨범 + 친구 5명 + 블루나비 | | | |
- 자라기 = **계절 옷**: 기본 포포 → 꽃 모자 포포(여름) → 튜브 포포(가을) → 목도리 포포(겨울) 처럼 받은 옷을 입고 다음 계절로. 얼굴·몸은 그대로라 같은 포포로 보인다. 옷마다 작은 효과(1탄 아이템처럼): 꽃 모자 = 한 번 8초 무적, 튜브 = 웅덩이 괜찮음, 목도리 = 회오리에 덜 밀림, 털모자 = 엔딩·다시 하기에서 얼음에 덜 미끄러짐.
- 방해 요소는 **단계마다 최대 2가지**만 (2026-11-04 사용자 수정). 1탄의 움직이는 거미줄은 2탄에서는 쓰지 않는다.
- 여행 지도 = **사계절 앨범**: 계절마다 사진 한 장(도장 대신 사진 '찰칵')과 **친구 스티커만** (2026-11-04 사용자 수정).
- **2탄에는 별이 아예 없다** (2026-11-04 사용자 결정): 미로 결과·대결 결과·앨범·기록 카드·엔딩 어디에도 별을 보여 주지 않는다. 미로 결과는 시간과 퐁 횟수만, 기록 카드는 계절별 시간과 사귄 친구.
- 표현 규칙(1탄과 같음): 자연·명소·음식·동물처럼 누구나 좋아하는 것만, 실제 상표·가게 이름·사람 고정관념은 쓰지 않는다.

## 1탄과 같은 것
- 미로(쓱 밀기·방향 버튼·키보드), 퐁! + [다시 시작], 체크포인트. 별은 없음(시간 기록만).
- 대결(놀자·꼬옥 버티기·특기 타이밍·냠냠 간식, 심술 게이지, 친구 되기), 게임오버 없음.
- 둘이서 하기(한 폰 / 각자 폰 대결장), 기념품 퐁퐁 **서울 사계절판**(봄 → 여름 → 가을 → 겨울 순서로 빨라짐, 계절 기념품: 벚꽃·연·수박·부채·은행잎·군밤·눈사람·붕어빵 같은 것), 저장 코드, 기록 카드, 도전장, 효과음, 살아 있는 미로 배경(꽃잎·물결·낙엽·눈 내림).

## 만드는 순서 (승인 뒤)
1. 화면 기획(`docs/design-brief.md` 13절) — 타이틀 1탄/2탄 고르기, 앨범, 옷 갈아입기 장면
2. 그림 트랙: **포포 캐릭터 시트 먼저 승인** → 친구 5명 → 수집품·방해물·계절 소품 (1탄처럼 Claude가 벡터로)
3. 개발: 2탄 데이터(`src/data/s2/`), 미로 4개, 대결, 앨범, 엔딩, 퐁퐁 서울판, 저장(2탄 칸)
4. 자동 완주 시험 → 미리보기 → (사용자 확인 후) 정식 주소
