# 블루나비의 세계여행 — 화면 기획서 (impeccable shape)

> 컨셉 v2(한국·중국·일본·미국·캐나다 7장, `docs/concept-v2.md`)가 이 기획서보다 우선한다. 지도는 "스탬프 투어 수첩" → **"블루나비 여권"**, 화면 틀은 7장(concept-v2 5절).
> 상태: **방향 승인됨 (2026-10-30)** — "창문이 넓어진다" + "스탬프 투어 수첩". 글꼴(주아·고운돋움)과 그림 방법(Claude 벡터) 결정됨.
> 근거: `PRODUCT.md`(제품 기록), 기획서 `references/`(scenario·systems·tech-spec·web-release·art-guide).
> 그림체·팔레트는 기획서 `art-guide.md`에 이미 정해져 있으므로(기획 우선) 새로 고르지 않고, 그 위에 **화면 틀(UI)과 흐름**을 정한다.

## 1. 누가, 어떤 상황에서

- **어른 친구들**이 카카오톡 단톡방 링크를 눌러 **갤럭시 폰의 카톡 인앱 브라우저**에서 처음 연다. 출퇴근길이나 쉬는 시간에 한 손으로 한다.
- 처음 3초 안에 "귀엽다, 해 볼까?"가 생겨야 하고, 그다음부터는 손이 기억하는 조작(스와이프·탭)만으로 끝까지 가야 한다.
- 화면 성격: **Experience**(게임 자체가 주인공). 타이틀만 첫인상을 책임지는 **Persuade** 역할을 겸한다.

## 2. 무엇을 해내야 하나

- 링크를 연 친구가 **타이틀 → 프롤로그 → 1장 미로**까지 설명서 없이 들어간다.
- 15~20분 안에 엔딩에 닿고, 캡처하고 싶은 장면 네 곳(진화, 친구 되기, 퍼즐 완성, 엔딩)에서 실제로 **공유 버튼을 누른다**.
- 다시 열면 바로 이어지고, 도전 링크를 받은 친구는 타이틀에서 바로 도전장을 본다.

## 3. 방향 — "창문이 넓어진다" + "스탬프 투어 수첩"

**핵심 생각**: 블루나비는 창문 안에 갇혀 있다가 세상으로 나간다. 그래서 **화면의 틀(대사창, 상단 상태 줄, 버튼 테두리)을 그 장의 '창'으로 만들고, 장이 넘어갈수록 틀이 얇아지고 넓어지다가 엔딩에서는 틀이 완전히 사라진다.** 무대가 넓어지는 느낌을 그림뿐 아니라 화면 구조로도 느끼게 한다.

| 장 | 화면 틀의 모습 | 느낌 |
|---|---|---|
| 프롤로그·1장 집 | 두꺼운 나무 창틀(`#b98a5e`)과 커튼 자락이 대사창·상태 줄을 감쌈 | 아늑하지만 갇혀 있음 |
| 2장 마을(밤) | 불 켜진 창문 틀(남색 `#1f2147` 위 노란 빛 `#ffe9a8` 테두리) | 어둠 속 작은 빛 |
| 3장 시장(아침) | 줄무늬 차양(`#e8584a`/흰색) 끝단이 틀 위쪽에 달림 | 열린 가게, 북적임 |
| 4장 세계여행 | 틀 없이 하늘 위 둥근 구름 판 | 탁 트임 |
| 엔딩 | 틀 없음. 화면 전체가 꽃밭과 하늘 | 세상 속 특별한 존재 |

**여행 지도 = 스탬프 투어 수첩**: 한국 어른이면 다 아는 축제·여행지의 "스탬프 투어"를 빌린다. 여행 지도는 펼친 수첩 한 쪽이고, 장을 깨면 그 장소 칸에 **도장이 쾅** 찍힌다(별 = 도장 속 별 칸, 친구 배지 = 칸 옆에 붙는 스티커). 마지막 4장은 "세계 꽃 축제" 칸이라 스탬프 투어가 실제 축제와 이어진다. 기록 카드도 이 수첩 한 쪽을 찍은 모습이라 친구에게 자랑할 맛이 난다.

**기획서 그대로 지키는 것**: 둥글고 말랑한 2D 플랫 그림체, 캐릭터만 외곽선 `#2b2d5a`, 볼터치 `#ff9fb8`, 장별 팔레트, 색 흐름(따뜻한 실내 → 밤 남색 → 아침 주황 → 밝은 꽃밭).

**글꼴 (제안)**: 제목·버튼은 둥근 손글씨 느낌의 **주아(Jua)**, 대사·설명은 읽기 편한 **고운돋움(Gowun Dodum)**. 둘 다 무료(OFL)로 웹에 넣을 수 있다. 한글 글꼴은 용량이 크므로 **게임에 실제로 쓰는 글자만 골라 넣어**(subset) 첫 다운로드 3MB 안에 맞춘다.

**정직한 위험**: 장마다 틀 모양이 바뀌므로 대사창·상태 줄을 장별로 4벌 그려야 한다. 처음에는 코드로 그린 단순한 틀로 시작하고, 공개용 그림 단계에서 다듬는다.

## 5. 상태와 범위 값

- **처음 / 이어하기**: 저장이 없으면 [이어하기]를 숨긴다. 저장이 막힌 브라우저면 타이틀에 "이 브라우저에서는 기록이 저장되지 않아요".
- **도전장 있음/없음**: 도전 링크로 들어오면 타이틀 위쪽에 띠, 지도 장소에 깃발. 코드가 깨졌으면 조용히 무시.
- **카톡 인앱 / 일반 브라우저 / 홈 화면 앱 / 파일로 실행 / PC**: 각각 보이는 안내가 다르다(인앱 띠, 설치 버튼 숨김, 서비스 워커 끔, QR).
- **대사 길이**: 한 대사 최대 3줄(34px, 폭 680). 넘치면 자동으로 다음 페이지.
- **닉네임**: 0~8글자, 비면 "익명의 블루나비".
- **기록 시간**: 0:30 ~ 99:59 표시. 최단 경로보다 짧은 기록은 표시하지 않음.
- **대결 진 경우**: "조금 쉬었다가 다시 해 보자!" → [다시 하기]. 친구 도전 진 경우: "아깝다! 다시 도전?".
- **그림 일부 없음**: 없는 그림은 임시 그림으로(게임은 멈추지 않음).

## 6. 화면 배치와 손맛 (720×1280 기준, 의도만)

- **엄지 영역 원칙**: 누르는 것은 모두 화면 아래 절반(y 820 이하)에, 보는 것은 위쪽에. 예외는 왼쪽 위 ‖ 일시정지와 오른쪽 위 건너뛰기(실수로 눌리지 않게 일부러 멀리).
- **타이틀**: 화면 위 60%는 창가 장면(창틀이 화면 테두리 역할), 제목 로고는 유리창에 붙은 스티커처럼. [시작]은 아래쪽 가장 큰 버튼. 누르면 **창문이 열리는 연출**과 함께 프롤로그로(이게 "창문이 넓어진다"의 첫 장면).
- **미로**: 스와이프는 화면 어디서나. 미로 칸은 장이 갈수록 작아지므로(60 → 44px) 블루나비는 늘 칸보다 살짝 크게, 수집품은 반짝 애니메이션으로 작아도 잘 보이게.
- **대결**: 보스 위 · 블루나비 가운데 · 버튼 아래 2×2(각 330×190). 심술 게이지는 **먹구름**이 줄어들며 66%·33%에서 보스 표정이 화남 → 시무룩 → 웃음. 특기 버튼은 쓸 수 없을 때 흐려지고 남은 턴 숫자 표시.
- **진화·친구 되기·퍼즐 완성·엔딩**: 화면 가운데 크게, 틀 없이, 아래에 [사진 남기기]. 공유하고 싶은 장면이 되도록 캐릭터를 화면 폭의 60% 이상으로.
- **장 넘어가기 연출(시그니처)**: 장을 깨면 카메라가 뒤로 빠지며 지금 장의 '창틀'이 화면 밖으로 밀려나고, 스탬프 수첩이 펼쳐져 **도장이 쾅**(효과음·진동 40ms). 다음 장을 누르면 새 장의 틀이 들어온다.
- **움직임 규칙**: 통통 튀는 튕김(살짝 넘쳤다 돌아옴)을 기본 움직임으로 통일. 화면 전환은 0.3~0.5초, 탭하면 빨리 감기. 파티클 30개 이하(진화만 잠깐 60개).
- **PC**: 세로 게임을 가운데 두고 양옆은 그 장의 테마 색 + "📱 폰으로 하면 더 재밌어요" QR. 키 안내는 마우스가 있는 기기에서만 작게.

## 8. 미로 배경 생동감 (2026-11-03, impeccable shape — 승인됨, 1~7장 완료 v1.1.0)

> 사용자 답: 나라별 특징이 살아나는 **질감과 소품 + 움직임**, 미로 판 **바깥 여백에도 나라 풍경**, **1장 먼저 시안** 보고 승인 후 2~7장.

**누가·무엇을**: 엄지로 미로를 미는 어른 친구. 장마다 "아, 이번엔 ○○에 왔구나"가 판을 보자마자 느껴져야 한다(제품 원칙 2: 무대가 넓어질수록 화면도 넓어지고 밝아진다). 그러면서도 **길·벽·수집품·방해물은 지금보다 덜 보이면 안 된다** — 배경은 놀이를 돕는 무대이지 주인공이 아니다.

**방향 — "살아 있는 무대, 조용한 바닥"**
- 세 층으로 나눈다: ① **바깥 풍경**(판 둘레·위아래 여백, 가장 자유롭게) ② **벽**(나라 소품이 사는 곳, 중간) ③ **바닥**(길, 가장 조용하게: 은은한 질감만).
- 움직임은 "숨 쉬는 정도": 느리고 작게, 화면 전체에 10~16개 안팎. 깜빡임·번쩍임 없음.
- **수집품과 헷갈리는 움직임은 쓰지 않는다**: 4장 대나무 잎·5장 벚꽃잎은 수집품이라 떨어지는 잎·꽃잎을 판 위에 날리지 않는다(바깥 여백에서만, 작고 흐리게).

**1장 한국 집 시안 (이번에 만들 것)**
| 층 | 지금 | 바꿀 모습 |
|---|---|---|
| 바깥 | 단색 | 벽지(작은 꽃무늬)와 판 아래 창턱: 화분·빛이 드는 창 한 조각 |
| 벽 | 갈색 블록 | 서랍장·책장 가구: 손잡이, 책등 몇 권, 위에 쿠션·작은 화분이 가끔 |
| 바닥 | 바둑판 | 마룻바닥 나뭇결(판자 줄 + 옹이), 군데군데 둥근 러그 |

**지켜야 할 조건**

- 기기에서 "동작 줄이기"를 켠 사람에게는 움직임을 멈춘다.
- 장별 색·소품 종류·움직임 개수는 `src/data/`(새 파일 `mazeLooks.js`)로 옮겨 기획자가 고칠 수 있게.

## 9. 퐁! 다시 시작 · 둘이서 하기 · 나라 효과음 (2026-11-03, impeccable shape — 승인됨, v1.2.0 완료)

> 사용자 답: 사라지는 효과는 **"퐁! 반짝이로 흩어짐"**, 다시 시작은 **체크포인트에서**, 2인용은 **한 폰 번갈아**. 효과음은 Claude가 알아서.

### 9-1. 퐁! 그리고 다시 시작
- **언제**: 순찰 방해물(청소기·수레·죽순·스케이트보드)에 닿을 때, 물방울이 떨어지는 웅덩이 칸에 있을 때(작은 우산이 있으면 그대로 괜찮음). 거미줄·바람·등불은 지금처럼(느려짐·밀림·끌림).
- **연출 (0.6초)**: 블루나비가 살짝 부풀었다가 "퐁!" 하고 비눗방울처럼 터지며 블루나비 색 반짝이 조각 8개가 동그랗게 흩어진다. 아프거나 깨지는 느낌이 아니라 "놀라서 숨었다"는 느낌. 도트: "앗, 퐁! 조금 쉬었다가 다시 해 보자!"
- **다시 시작 버튼**: 판 가운데 위로 둥근 큰 버튼 [다시 시작] (터치 96px 이상, 키보드 Space·Enter). 버튼이 떠 있는 동안 시간은 멈춘다.
- **누르면**: 마지막 체크포인트(없으면 시작 자리)에 반짝이가 모이며 블루나비가 다시 나타난다. 모은 수집품·시간은 그대로. 잠깐 깜빡이며 1초 동안 안 닿는다.
- 기록 창의 "데구르르 N번"은 "퐁 N번"으로.

### 9-2. 둘이서 하기 (한 폰 번갈아)
- **입구**: 타이틀에 [둘이서 하기] 버튼 (여행 시작·블록 퍼즐 아래).
- **준비 화면**: 두 사람 이름(비워 두면 "1P"·"2P", 8글자) → 나라 고르기(이 기기에서 열린 나라만. 처음이면 1장 한국 집부터).
- **흐름**: "1P 차례! 폰을 1P에게 주세요" 카드 → 1P 미로 → "2P 차례! 폰을 넘겨 주세요" 카드 → 2P 같은 미로 → **결과 화면**: 두 사람 시간·퐁 횟수, 더 빠른 사람이 이김("○○ 승리!", 같으면 "둘 다 멋졌어!"). [다음 나라로] · [다시 겨루기] · [처음 화면으로].
- **이야기와 따로**: 둘이서 하기는 보스 대결·대사·저장·별·여권에 영향을 주지 않는다. 지는 쪽에도 놀리는 말 없음.
- 그 나라의 블루나비 모습(애벌레·나방·나비)을 그대로 쓴다. 2P는 같은 블루나비에 머리 위 작은 "2P" 표시.

### 9-3. 나라 효과음 (Web Audio로 만든 짧은 소리, 소리 끄기 설정을 따름)
- **나라에 도착할 때(장 시작)**: 나라마다 다른 짧은 2~3음 인사 소리 (한국 집 따뜻한 오르골, 밤 골목 낮은 종, 시장 통통 마림바, 중국·일본·미국·캐나다는 음색과 음 높이를 달리한 밝은 소리). 특정 나라를 흉내 내는 고정관념 음악은 쓰지 않는다.
- **여권 도장 "쾅"**: 지금보다 묵직한 도장 소리 + 별 개수만큼 "띵".
- **진화**: 고치가 열릴 때 올라가는 반짝 소리.
- **퐁**: 작은 "퐁", 다시 시작은 "뾰롱".
- **둘이서 하기**: 차례 바뀜 "딩동", 승리 짧은 팡파르.

### 확인할 것
- 1장 자동 완주(방해물에 일부러 닿아 퐁 → 다시 시작 확인), 둘이서 하기 1장 한 판, 375×667·430×932 잘림 없음, 소리 끄기 설정에서 조용함, 콘솔 오류 없음.

## 10. 두 번째 놀이 바꾸기 — "기념품 퐁퐁" (2026-11-03, impeccable shape — 승인됨, v1.3.0 완료)

> 사용자 요청: 블록 퍼즐을 테트리스로, 앞에서 새로 그린 배경 넣기, 2인 대결, 지도 순서대로 빨라지기.
> 테트리스 자체는 다른 회사의 게임이라 그대로 만들지 않고, **같은 "떨어지는 블록" 갈래의 블루나비 고유 규칙**으로 만든다.
> 답: 규칙 **기념품 짝짓기**, 단계 **해외 4개국**, 2인 **한 화면 동시 대결**, 지금 그림 퍼즐은 **새 게임으로 바꾸기**.

### 놀이 규칙 (혼자 하기)
- 판 6칸 × 12줄. 위에서 **기념품 두 개 한 묶음**이 떨어진다. 쓱 밀어 좌우로 옮기고, 톡 눌러 돌리고, 아래로 쓱 밀면 빨리 내린다 (PC: ←→ 이동, ↑ 돌리기, ↓ 빨리, Space 바로 내리기).

- 나라마다 목표(예: 기념품 30개 퐁)를 채우면 여권처럼 도장이 찍히고 **다음 나라로**: 중국 → 일본 → 미국 → 캐나다. **지도 순서대로 떨어지는 속도가 빨라진다** (예: 0.8초 → 0.65초 → 0.5초 → 0.38초에 한 칸, 수치는 `src/data/`에서 조정).

### 흐름 (미로·퐁퐁 공통)
1. **방 만들기** — [둘이서 하기] / [둘이서 대결] 첫 화면에 **[한 폰으로]** · **[각자 폰으로]** 두 갈래. 각자 폰으로 → 나라 고르기 → [대결장 보내기]: 카카오톡 공유 창(안 되면 링크 복사)으로 `#d=D1-…` 링크를 보낸다.
   - 대결장 안에 든 것: 놀이(미로/퐁퐁), 나라, **같은 판을 만드는 번호(시드)**, 보낸 사람 닉네임, 대결 번호.
2. **받은 사람** — 링크를 열면 타이틀 위 띠 대신 바로 "○○의 대결장! 2단계 · 중국 미로" 카드 → [시작]. 이 기기에서 아직 안 연 나라여도 대결은 할 수 있다(이야기 저장에는 영향 없음).
3. **둘 다 각자 폰에서 시작** — "셋, 둘, 하나, 출발!" 카운트다운 후 시작. 같은 방에 있으면 소리 내어 같이 누르면 되고, 떨어져 있어도 기록으로 겨루므로 시작 시각이 달라도 공평하다.
4. **끝나면 결과 카드** — 내 기록 + [결과 보내기](`#d=` 같은 대결 번호 + 내 기록). 상대 결과 링크를 열면 **두 사람 기록이 나란히 + 승리 왕관**. 먼저 끝난 쪽은 "친구 결과를 기다리는 중 — 결과 링크를 받으면 열어 보세요".
   - 결과는 이 기기에 대결 번호별로 저장(최근 5개, 도전장함 옆 **대결함**).

### 미로 (각자 폰)
- 같은 나라 미로를 각자 한 판. **더 빨리 출구에 닿은 사람 승리**(같으면 퐁 횟수가 적은 쪽). 움직이는 웅덩이·거미줄 박자도 출발 순간부터 같게 맞춘다.
- 대사·저장·별·도전장 없이 미로만 (지금 둘이서 하기와 같음).
- (만들면서 정함) 각자 폰 미로는 아이템(반짝가루·우산·목도리·피리) 없이 — 가진 아이템이 서로 달라서 공평하게.

### 기념품 퐁퐁 (각자 폰)
- 같은 시드 → **두 폰에 똑같은 순서로 기념품이 떨어진다**. 나라별 속도 그대로.
- **2분 점수 대결**: 2분 동안 더 많은 점수를 낸 사람 승리. 구름 블록은 상대 폰으로 보낼 수 없어서(연결 없음) 각자 폰 대결에서는 쓰지 않는다.
- 꼭대기에 닿아도 지지 않는다: "퐁!" 하고 판 위쪽 절반이 비워지고 이어서 (점수 그대로, 게임오버 없음 원칙).

### 화면
- 대결장·결과 카드는 지금 도전장과 같은 결(여권 종이 + 창틀), 1P 하늘색 · 2P 분홍 이름 칩, 승리 쪽 왕관.
- PC에서도 똑같이(링크 복사 · 키보드).

### 확인할 것
- 두 브라우저(창 두 개)로 미로·퐁퐁 각각: 대결장 보내기 → 열기 → 각자 플레이 → 결과 링크 교환 → 양쪽에 같은 승패.
- 같은 시드에서 두 폰 퐁퐁 기념품 순서가 같은지 자동 검사, 옛 링크(C1·C2·D 아닌 것)와 섞여도 문제없는지, 카카오톡 인앱에서 링크가 열리는지.

## 14. 모바일 최적화 (1탄·2탄 공통, 2026-11-04 — 승인됨, v2.1.0)
> 사용자 지시: "1탄, 2탄 둘 다 모바일 최적화 게임으로 수정해". 점검 결과(아래 숫자)를 바탕으로 한 안.

### 점검 결과
- 처음 열 때 앱 저장(서비스 워커)이 **그림 전부 7.4MB**를 한꺼번에 받는다 → 4G·데이터 요금에 부담, 첫 화면도 느려짐.
- 1탄을 해도 2탄 그림(3.8MB), 2탄을 해도 1탄 그림(약 5MB)을 뒤에서 다 받는다.
- 그림 파일이 압축이 덜 된 PNG (대결용 큰 그림 한 장이 100~300KB).
- 기준 화면에서 22px보다 작은 글자 14곳 → 폰(가로 약 390)에서는 10~11px로 보여 읽기 어려움.
- 화면이 길쭉한 폰(20:9)에서는 위아래가 남아 게임이 작게 보인다.

### 고칠 것
1. **처음 받는 양 줄이기**: 앱 저장은 코드·글꼴·첫 화면 그림만 미리, 나머지 그림은 쓰는 순간 받아 저장(한 번 받으면 인터넷 없이도). 목표: 첫 방문 3MB 이하(지금 7.4MB+).
2. **하는 탄 그림만 받기**: 1탄이면 1탄 그림만, 2탄을 처음 누를 때 2탄 그림을 받는다("2탄 그림 가져오는 중…" 짧게).
3. **그림 가볍게**: 색 수를 줄인 PNG로 다시 굽기(보기엔 같게) → 그림 전체 약 절반으로.
4. **작은 글자 키우기**: 최소 22px(폰에서 약 12px)로, 버튼 안 글자는 26px 이상.
5. **긴 폰 화면 활용**: 화면이 길면 위아래 여백에 그 단계 색·풍경을 채우고, 미로와 버튼은 엄지가 닿는 아래쪽으로 조금 내림. 노치·홈 바 안전 영역 그대로.
6. **느린 폰 배려**: 기기가 느리면(초당 그림 수가 떨어지면) 배경 움직임을 자동으로 줄이고, 다른 앱에 갔다 오면 소리·움직임을 멈춘 채 일시정지(지금처럼).
7. **확인**: 갤럭시(360×780·412×915)·아이폰(375×667·430×932) 크기 화면 사진, 4G 느린 속도 흉내로 첫 화면 시간 재기(목표 3초), 카카오톡 인앱 브라우저 흉내.

## 15. 인트로 해설 음성 · 달리기 에너지 · 톡 눌러 길 찾아 가기 (2026-11-06, impeccable shape — 승인됨 "15,16,17 진행해", v3.0.0)
> 사용자 답: **해설 줄만 읽기** / **달리기 에너지** / **누른 칸까지 길 찾아 가기** / **1탄·2탄 모두**.

### 1) 인트로 해설 음성 (TTS 해설자)
- 프롤로그(1탄 "어느 집 거실…", 2탄 "서울 어느 골목…")의 **해설(나레이션) 줄만** 폰에 들어 있는 한국어 음성(브라우저 음성 합성)으로 읽는다. 캐릭터 대사·조작 안내는 지금처럼 글로만.
- 이야기 들려주는 차분한 목소리: 한국어 목소리 중 가장 자연스러운 것(아이폰은 보통 '유나'), 빠르기 조금 느리게, 높이 조금 밝게.
- 읽는 동안 대사창에 작은 스피커 그림이 움직이고, 배경음은 잠깐 작아진다. 톡 눌러 넘기면 읽기도 멈추고 다음 줄로.
- 1탄 프롤로그에 해설 한 줄을 더해 장면을 열어 준다: "아직 이름도 없는 작은 애벌레는, 창밖의 넓은 세상이 궁금했어요."
- [소리] 설정 하나로 함께 켜고 끈다. 음성이 없는 브라우저(일부 인앱 등)는 조용히 글만. 서버·파일 없음.

### 2) 달리기 에너지
- 미로 위쪽 상태 줄에 **에너지 게이지**(번개 그림 + 막대). 처음 가득(100).
- **한 칸 움직일 때마다 조금씩 준다**(1). **수집품을 먹으면 +30**, **체크포인트에 닿으면 적어도 절반(50)까지** 찬다.
- **0이 되면 멈추지 않고 천천히 기어간다**(걸음 2배 느림) + 도트/블루나비 말: "헥헥, 힘이 없어… 꽃씨를 먹으면 힘이 날 거야!" 게임오버 없음.
- 막대 색: 넉넉하면 초록 → 반쯤 노랑 → 조금 남으면 주황(색만으로 말하지 않게 숫자 칸도 함께).
- 길을 아끼며 움직이는 재미가 생기도록, 단계마다 최단 길로 다니면 0이 되지 않는 정도로 맞춘다(수치는 `src/data/ui.js` `energy`).
- 퐁!(다시 시작)해도 에너지는 그대로. 둘이서 하기·각자 폰 대결에도 같은 규칙(공평).
- 2탄 포포도 같은 규칙, 말만 포포("멍… 지쳤어, 맛있는 걸 먹으면 힘이 날 거야!").

### 3) 톡 눌러 길 찾아 가기
- 미로 판의 칸을 **톡 누르면 그 칸까지 가장 가까운 길을 알아서 걸어간다**(순간이동 아님 — 방해물·웅덩이·바람은 그대로 만난다).
- 가는 길을 **점선**으로 잠깐 보여 주고, 도착하면 사라진다. 지나가며 수집품도 줍는다.
- 가는 도중 다른 칸을 누르면 그쪽으로 바로 바뀌고, **블루나비(포포)를 톡 누르면 멈춘다**. 쓱 밀기·방향 버튼·방향키는 지금 그대로.
- 벽을 누르면 그 옆의 가장 가까운 길 칸으로 간다. 바람·등불에 밀려 길에서 벗어나면 그 자리에서 다시 길을 찾는다.
- 1단계 첫 안내 문구를 "쓱 밀거나, 가고 싶은 곳을 톡 눌러요"로.

### 4) 친구가 생길 때마다 쓸모 있는 아이템 (2026-11-06 사용자 추가 요청)
> "친구들이 하나둘씩 생길 때마다 빨리 달릴 수 있는 자전거, 방해물을 없앨 수 있는 도구 같은 아이템을 얻게"

- 미로 오른쪽 아래 **아이템 줄**: 가진 아이템이 둥근 버튼으로 나란히(최대 4개, 버튼 96px 이상), 미로마다 아이템마다 1번씩. 쓴 버튼은 흐려진다.
- 방해물을 '없앤다'는 무찌르는 느낌이 아니라 **비눗방울에 싸여 둥실 날아가는** 모습으로(게임 원칙: 다치는 표현 없음).

| 1탄 친구 | 선물 | 쓰면 |
|---|---|---|
| 먼지몽 | 반짝가루 (지금 그대로) | 8초 동안 무엇에 닿아도 괜찮음 |
| 실실이 | 실 목도리 (그대로) | 바람에 1칸만 밀림 (늘 켜짐) |
| 짹짹이 | **씽씽 자전거** (새로) | 10초 동안 2배 빠르게, 그동안 에너지가 줄지 않음 |
| 빵빵이 | 대나무 피리 (그대로) | 가장 가까운 수집품 쪽 길 안내 |
| 사뿐이 | 작은 우산 (그대로) | 물방울·웅덩이 괜찮음 (늘 켜짐) |
| 도토리대장 | **비눗방울 막대** (새로) | 둘레 3칸 안의 방해물(청소기·수레·스케이트보드·웅덩이·거미줄)이 비눗방울에 싸여 둥실 날아가 이 판에서 사라짐 |
| 댐댐이 | **꿀 도시락** (새로) | 에너지 가득 채우기 |
| 붕붕대장 | (엔딩) | — |

- 2탄 포포도 같은 아이템을 친구에게서 받는다(계절 옷 선물은 그대로, 하나씩 더): 깍깍이 → 씽씽 킥보드(자전거와 같은 효과), 개굴이 → 꿀 도시락, 밤톨이 → 비눗방울 막대.
- 각자 폰 대결에서는 지금처럼 아이템 없이(공평).
- 이미 그 친구를 사귄 저장은 다음에 미로를 열 때 새 아이템이 자동으로 들어온다.

### 확인할 것
- 아이템 줄: 버튼 4개까지 겹치지 않음(375×667·430×932), 자전거 10초·비눗방울 3칸·꿀 도시락 동작, 옛 저장에 새 아이템 들어오기.
- 아이폰 사파리에서 해설 음성(첫 탭 뒤), 소리 끄면 안 나옴, 넘기면 멈춤.
- 단계마다 최단 길로 깼을 때 에너지가 0이 안 되는지 자동 계산, 0이 되면 느려지고 수집품으로 회복.
- 톡 이동: 길·벽·멀리 있는 칸·가는 중 다시 누르기·블루나비 누르기, 1탄·2탄·둘이서·각자 폰 대결, 자동 완주 시험.

## 16. 게임 입구 — 펼친 세계지도 위의 지구본 (2026-11-06, impeccable shape — 승인됨, v3.0.0)
> 사용자 요청: "처음 화면에 블루나비 세계여행 게임 입구 이미지를, 펼쳐 있는 세계지도 안의 지구본 모형으로, 1탄·2탄을 터치해서 들어가게"

### 화면 (새 씬 `Entry`, 게임을 켜면 가장 먼저)
- **바탕 = 책상 위에 펼친 옛 세계지도**: 크림색 종이, 접힌 자국, 둥근 대륙 모양(나라 경계선·국기 없음 — 6절 나라 표현 규칙), 바다엔 물결 줄, 모서리에 나침반 그림. 지도 위에 블루나비가 지난 여행길(한국 → 중국 → 일본 → 미국 → 캐나다)이 점선으로 은은하게.
- **가운데 = 지구본 모형**: 나무 받침 + 금빛 반원 고리 + 파란 바다·초록 대륙의 공. 천천히 빙글(동작 줄이기면 멈춤), 살짝 반짝.
- **지구본 위 핀 두 개 = 입구**:
  - **1탄 핀**(파란 나비 모양): 「블루나비의 세계여행」 — 지구를 한 바퀴 도는 여행길 위
  - **2탄 핀**(강아지 발바닥 모양): 「포포의 사계절 서울」 — 한반도 위 한 점
  - 핀마다 아래에 큰 이름표 카드(주인공 얼굴 + 제목, 버튼 96px 이상) — 핀이 작아도 카드를 눌러 들어갈 수 있게.
- 위쪽 제목: "어디로 여행할까요?" (주아), 아래 작은 글: 버전·설정(톱니).
- 마지막에 하던 탄의 핀이 살짝 통통 튄다.

### 들어가기
- 핀이나 카드를 톡 → 지구본이 그 핀 쪽으로 빙글 돌며 확대 → 그 탄의 타이틀(1탄 창가 / 2탄 포포네 마당)로.

### 그림·성능
- 지도·지구본은 Claude가 벡터로 그려 한 장으로 굽는다(1탄 그림체: 둥글고 외곽선 진한 남색). 첫 화면 그림이라 boot 그룹, 가볍게(100KB 안쪽 WebP).

## 17. 미로 안에서 숨바꼭질로 친구 되기 (2026-11-06, impeccable shape — 승인됨, v3.0.0)
> 사용자 요청: "친구를 각각 놀면서 사귀는 게 아니라 미로게임 안에서 놀고 마지막 나가는 출구에서 친구가 되는 것으로". 답: **숨바꼭질 친구** / **1탄·2탄 모두**.

### 바뀌는 흐름
- 지금: 미로 → (출구) → 턴제 대결 화면(심술 게이지) → 친구
- 바뀜: **미로 안에서 숨바꼭질 → 출구에서 친구 되기** (턴제 대결 화면은 이야기에서 빠짐)

### 숨바꼭질
- 심술 난 친구가 미로 안에 숨어 있다. 벽 뒤로 **귀·머리끝이 살짝 보이고 바스락** 움직여서 찾을 수 있다(완전히 안 보이게 숨지 않음).
- 블루나비(포포)가 친구가 있는 칸에 닿으면 **"찾았다!"** → 친구가 깔깔 웃으며 반짝 사라졌다가 다른 숨는 곳(막다른 길 위주)에 나타난다. 친구 머리 위·상태 줄에 **하트 3칸**, 찾을 때마다 하나씩 찬다.
- **세 번 찾으면** 심술이 스르르 풀리고 친구가 **출구 앞으로 가서 기다린다**.
- 친구는 방해물이 아니다: 닿아도 퐁! 하지 않는다. 숨는 곳은 시드 고정(둘이서·각자 폰 대결도 공평), 출발·출구·체크포인트 근처는 피한다.
- **출구 열림 = 수집품 다 모으기 + 친구 모두 찾기(하트 가득).**
- 친구가 여럿인 단계: 1탄 한국은 **구역마다 한 친구**(집 먼지몽 · 밤 골목 실실이 · 시장 짹짹이), 캐나다는 댐댐이·붕붕대장이 판 전체에, 2탄 겨울은 뭉치·곰실이.

### 출구에서 친구 되기
- 출구에 닿으면 기다리던 친구(들)와 짧은 대사 → **"○○와 친구가 됐어!"** + 선물(15절 아이템 포함) → 진화·옷 갈아입기 / 여권·앨범.
- 친구 대사는 숨바꼭질에 맞게 새로 쓴다: 처음 마주칠 때 "흥, 나 못 찾지? 세 번 찾으면 인정해 줄게!", 찾을 때 "앗, 들켰다!", 출구에서 "헤헤, 이렇게 신나게 논 거 처음이야!" 같은 결.
- 1탄 별 세 번째는 "기운 절반 남기고 승리" 대신 **"에너지 절반 이상 남기고 출구"**(15절 달리기 에너지와 연결). 2탄은 별 없음 그대로.
- 게임 원칙 그대로: 무찌르지 않고 친구가 되고, 지는 일·게임오버 없음.

### 함께 바뀌는 것
- 둘이서 하기·각자 폰 대결: 같은 숨바꼭질 규칙(기록 = 친구 다 찾고 출구까지 시간).
- 여권·앨범·엔딩·기록 카드: "○턴 만에" 같은 대결 기록 대신 미로 시간만.
- 옛 저장이 대결 화면 중이었으면 그 단계 미로부터 다시(친구·선물 유지).

### 확인할 것
- 단계마다 숨는 곳이 막힌 곳 없이 닿을 수 있는지 자동 검사, 하트 3칸·출구 열림 조건, 한국 구역별 친구, 1탄·2탄 자동 완주, 둘이서·각자 폰 대결.

### 만들면서 정한 것 (15~17절, v3.0.0)
- 에너지 수치: 한 칸 -1.2, 수집품 +30, 친구 찾기 +10, 체크포인트 50까지, 0이면 2배 느림. 가까운 순서로 다 돌면 단계마다 출구에서 53~79가 남는다(별 기준 50) — `npm run check:maze`가 계산.
- 별 기준 시간은 숨바꼭질만큼 늘림: 한국 2:55 · 중국 2:05 · 일본 2:15 · 미국 2:10 · 캐나다 2:30.
- 상태 줄을 3줄로(단계·시간 / 수집품 / 에너지·친구 하트), 미로는 y 158부터(칸 크기는 그대로).
- 숨는 자리: 크림색 쿠션 뒤로 친구 머리가 빼꼼, 들썩들썩. 수집품·방해물과 헷갈리지 않는 색.
- 톡 이동은 바람 칸을 '밀려 내려앉는 칸'까지 한 번에 계산(바람을 거슬러 헛돌지 않게), 자꾸 밀려나면 그만.
- 아이템 버튼은 최대 5개(입구 기획의 4개에서 — 1탄을 다 깨면 5개가 됨), 버튼 96px, 짧은 이름.
- 지구본·지도는 그림 파일 대신 Graphics로 그림(첫 화면 0KB 추가). 지구본은 대륙 덩어리를 옆으로 흘리며 가장자리에서 납작하게.
- 입구에서 연 설정에는 '저장 코드 복사'·'처음부터'를 숨김(탄이 정해지지 않아서).

## 18. 세로·가로 자유롭게 — 모바일 가로 화면 (2026-11-06, impeccable shape — 승인됨 "이대로 진행해", v3.3.0)
> 사용자 요청: "세로, 가로 모드 자유롭게 바뀔 수 있게". 답: **PC처럼 가운데 작게가 아니라, 모바일 최적화로 가로·세로 다 적용되게**.

### 왜 따로 배치가 필요한가
- 지금 모든 화면은 세로 720×1280 기준. 폰을 가로로 들면 높이가 약 1/2.2로 줄어, 그대로 맞추면 글자가 22px → 약 7pt로 읽을 수 없다.
- 그래서 **가로일 때는 기준 화면을 1280×720(가로)** 으로 바꾸고, 화면마다 가로 배치를 따로 둔다. 글자 최소 22px 규칙은 가로 기준 화면에서도 그대로.

### 돌릴 때
- "폰을 세워 주세요" 덮개를 없앤다. 돌리면 0.3초 안에 그 화면을 새 방향으로 다시 그린다.
- 하던 것은 이어진다: 미로(위치·수집품·숨은 친구 하트·에너지·시간), 여권 쪽, 대사(몇 번째 줄), 퐁퐁 판. 돌리는 동안은 시간이 멈춘다.
- 길쭉한 폰 빈 띠 줄이기(3.1.0)는 가로에서도: 가로 기준 폭을 화면 비율대로 1280~1600.

### 화면별 가로 배치
| 화면 | 가로 배치 |
|---|---|
| 지구본 입구 | 왼쪽 지구본, 오른쪽에 1탄·2탄 카드 위아래 |
| 타이틀 1·2탄 | 왼쪽 그림(창가 / 포포네 마당), 오른쪽 제목 + 버튼 세로로 |
| **미로** | 왼쪽 세로 띠(220px): 단계·시간·수집품·에너지·숨은 친구 하트·일시정지 / 가운데 미로를 높이에 맞춰 크게 / 오른쪽 띠: 아이템 버튼 세로 + 말풍선. 방향 버튼은 오른쪽 아래 십자 |
| 대사창 | 아래 가로로 넓은 창(높이 220), 얼굴은 왼쪽 |
| 여권(1탄) | **펼친 여권 두 쪽**: 왼쪽 쪽 = 입국 도장·단계 정보, 오른쪽 쪽 = 친구 증명사진 칸 |
| 사계절 앨범(2탄) | 왼쪽 사진, 오른쪽 친구 스티커 |
| 기념품 퐁퐁 | 혼자: 가운데 판 + 양옆 점수·다음 블록 / 둘이서: 두 판 나란히 (가로가 더 자연스러움) |
| 일시정지·설정·결과 창 | 가운데 판을 낮고 넓게(2열 버튼) |
| 진화·옷 갈아입기·엔딩 | 가운데 그림 + 아래 글, 높이에 맞춰 줄임 |

### 만드는 순서
1. 화면 틀: 방향 감지·기준 화면 바꾸기·돌릴 때 이어서 다시 그리기 (`src/ui/layout.js` 한 곳에서, 화면은 `L.landscape`·`L.w`·`L.h`만 본다)

### 확인할 것
- 아이폰(가로 844×390)·갤럭시(가로 915×412)·태블릿·PC에서 글자 22px 이상, 버튼 96px 이상, 노치·홈 바 피하기(가로에선 왼쪽·오른쪽 안전 영역)

### 만들면서 정한 것 (18절, v3.3.0)
- 가로 배치는 처음엔 터치 기기만이었으나 2026-11-06 '모바일 전용'으로 바뀌어 **창이 가로면 어디서나** 가로 배치(PC 옆 QR 없음).
- 화면마다 처음부터 다시 짜는 대신, 기준 좌표(720×1280)는 그대로 두고 **카메라를 조금 줄여(0.8~0.9배) 보며 버튼·칸을 옆으로 옮기는** 방식(`landscapeView()`). 미로·입구만 캔버스 좌표로 새로 배치. 그래서 일부 화면(퐁퐁 게임 중 0.65배, 진화·엔딩 연출 0.58배)은 글자가 조금 작아진다 — 대사는 대사창(줄이지 않음)으로 읽혀서 괜찮다.
- 돌릴 때 이어지는 것: 미로(위치·수집품·하트·에너지·시간·쓴 아이템), 여권·앨범 쪽, 타이틀·입구·둘이서·대결 화면. 대사·일시정지·설정 창이 떠 있으면 닫힌 뒤에, 퐁퐁 게임 중·진화·엔딩 연출 중에는 끝난 뒤에 새 방향으로 바뀐다(그동안은 예전 배치로 맞춰 보임).
- 주소창이 나타났다 사라지는 정도(60 미만)는 다시 그리지 않는다.

## 19. 한 화면 홈 「블루나비와 포포의 여행」 + [같이 하기] (2026-11-10, impeccable shape — 승인됨 "이대로 진행해", v3.8.0)
> 사용자 요청: "1탄·2탄 지구본에서 들어가면 보이는 화면을 블루나비와 포포의 여행 이미지·제목에 어울리게, 들어가면 기념품 퐁퐁과 여행 게임을 둘이나 3명이서 같이 할 수 있게 합쳐줘".
> 답: 타이틀 = **한 화면으로 합치기** / 합치는 방식 = **[같이 하기] 한 버튼**(안에서 인원·놀이를 고름, 혼자 퐁퐁도 그 안에) / 3명 = **각자 폰 대결 링크**(서버 없음).

### 흐름
- 지구본 입구 → (나비 핀·발바닥 핀·이름표 카드 무엇을 눌러도) → **홈** 한 화면. 지금의 1탄 타이틀(창가 화분)·2탄 타이틀(서울 울타리)은 홈 하나로 바뀐다. 누른 탄의 버튼이 홈에서 한 번 반짝인다.
- 대결장·도전장 링크로 들어오면 지금처럼 바로 대결 화면.

### 홈 화면 (세로)
- **배경 = 썸네일과 같은 그림**: 하늘·구름, 왼쪽 아래 튤립 꽃밭 언덕(1탄의 끝), 오른쪽 서울 빌딩·남산 타워(2탄), 바닥 잔디. 파일 없이 그리기(첫 화면 가볍게).
- **로고 카드**(크림색 카드, 남색 테두리): 큰 글씨 "**블루나비**와 **포포**의 여행"(블루나비 파랑·포포 분홍).
- 로고 아래 **블루나비(왼쪽)·포포(오른쪽)** 가 서로 보며 통통 뛴다.
- 버튼 3개(세로로, 엄지 닿는 아래쪽):
  1. **[1탄 세계여행]** 파랑 — 아래 작은 글 "처음부터" 또는 "이어하기 · 3단계 일본"
  2. **[2탄 사계절 서울]** 분홍 — 같은 식("이어하기 · 여름")
  3. **[같이 하기]** 주황 — "2~3명 · 미로 / 기념품 퐁퐁"
- 위: 왼쪽 [◀ 지구본], 오른쪽 설정 톱니. 오른쪽 아래 버전. 새 버전 안내·홈 화면 추가 안내 등 타이틀이 하던 일은 홈으로 옮긴다.
- 1탄·2탄 버튼: 그 탄으로 바꾸고 지금 [여행 시작/이어하기]와 똑같이(처음이면 바로 1단계 미로, 이어하기면 미로·여권/앨범).
- **가로**: 왼쪽 반 = 로고 + 블루나비·포포, 오른쪽 반 = 버튼 3개 세로.

### [같이 하기] 화면 (새 화면 하나, 위에서 아래로 고르기)
1. **몇 명?** [혼자] [2명] [3명]
2. **무엇을?** [미로 여행] [기념품 퐁퐁] — 혼자는 퐁퐁만(혼자 미로는 홈의 1탄·2탄 버튼).
3. **어디서?** 판 고르기: 1탄 나라·2탄 계절을 한 줄에(이 기기에서 열린 곳만, 지금 규칙 그대로). 퐁퐁 판도 1탄 4개국 + 2탄 계절.
4. **어떻게?** 2명 → [한 폰으로](미로 번갈아 / 퐁퐁 한 화면 두 칸) · [각자 폰](대결장 링크) / 3명 → 각자 폰만("3명은 링크를 단톡방에 올려 겨뤄요" 한 줄).
5. [시작하기] → 지금 있는 놀이 화면으로(둘이서 미로, 퐁퐁 혼자·한 화면 대결, 대결장 보내기). 이름 입력은 지금처럼.
- 아래 [대결함]·[홈으로]. 가로: 왼쪽에 1·2, 오른쪽에 3·4·시작.

### 3명 각자 폰 대결 (대결장 링크 넓히기, 서버 없음)
- 대결장 링크에 **인원(2·3)** 을 넣는다. 결과 링크는 지금처럼 각자 자기 기록만 담아 보낸다.
- 받은 결과 링크마다 대결 카드의 칸을 채운다(나 + 친구 최대 2명). 3명이면 단톡방에 각자 결과 링크를 올리고, 다른 두 사람 링크를 열면 **1·2·3등**이 보인다.
- 대결 카드: 등수 리본 + 이름 + 기록(미로 = 시간·퐁 횟수, 퐁퐁 = 점수), 아직 안 한 사람은 "기다리는 중".
- 새 링크 앞글자 `D2-`, 옛 `D1-`(2명) 링크도 그대로 읽는다. 대결함은 최근 5개 그대로. 닉네임·기록은 플레이어가 보낸 링크 안에만(개인정보 그대로).

### 바뀌거나 없어지는 것
- 1탄 타이틀(창가 화분·창문 스티커)·2탄 타이틀(울타리·포포 마당) 화면 → 홈 하나. 타이틀로 가던 버튼(여권·앨범·둘이서·퐁퐁·대결·엔딩의 "처음 화면으로")은 모두 홈으로.
- 타이틀의 [기념품 퐁퐁]·[둘이서 하기] 버튼 → [같이 하기] 하나로.
