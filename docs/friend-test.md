🦋 블루나비의 세계여행이 완성됐어요!

파란 애벌레 블루나비가 한국 집 화분에서 출발해 중국·일본·미국을 지나 캐나다 꽃밭까지 여행하며 나비가 되는 게임이에요. 설치·가입 없이 링크만 누르면 바로 돼요. (약 35분, 중간에 꺼도 이어서 할 수 있어요)

👉 https://blue-naby-game.web.app

- 카톡 안에서 열려도 되지만, 아래 초록 띠의 [브라우저로 열기]를 누르면 기록이 더 안전하게 남아요
- 홈 화면에 추가하면 앱처럼 꽉 찬 화면으로 할 수 있어요
- 블록 퍼즐도 있어요 (5조각부터 20조각까지)
- 여권 왼쪽 위 [자랑하기]로 기록 카드나 도전장을 보내서 미로 기록 겨뤄 봐요!
- 이상하거나 어려운 곳은 설정(톱니바퀴) → [의견 보내기]로 알려 주세요

광고도 결제도 없고, 개인정보도 모으지 않아요. 재밌게 해 줘요! 💙
