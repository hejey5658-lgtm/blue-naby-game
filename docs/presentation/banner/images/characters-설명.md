# 캐릭터 설명 (bluenabi.png · popo.png)

## 블루나비 — 1탄 「세계여행」 주인공
- **한 줄**: 세상이 궁금한 파란 나비, 나라마다 풍경 속 다른 곳을 찾아요.
- **소개**: 동글동글 파란 몸에 큰 눈, 발그레한 볼이 귀여운 블루나비. 중국·미국·캐나다를 여행하며 나라마다 펼쳐진 두 장의 풍경 그림에서 다른 곳을 찾아요. 싸우지 않고 천천히 들여다보는 다정한 여행자예요.
- **그림 속 모습**: 하트 무늬 날개를 활짝 편 **나비** 모습 (게임 그림 속 모습 그대로)

## 포포 — 2탄 「서울여행」 주인공
- **한 줄**: 블루나비의 친구, 서울의 봄·가을·겨울을 누비는 아기 강아지예요.
- **소개**: 하얀 털에 귀 끝만 연한 갈색인 아기 강아지 포포. 봄·가을·겨울 서울을 여행하며 계절 풍경 그림 속 다른 곳을 찾아요. 계절마다 옷차림(꽃 모자·목도리·털모자)이 바뀌어요.
- **그림 속 모습**: 노란·분홍 꽃 모자를 쓴 **봄** 모습
