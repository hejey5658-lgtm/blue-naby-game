# 메인 게임 이미지 설명 (main-scene.png)

## 한 줄 설명 (그림 아래 캡션용)
1탄 「세계여행」 2단계 · 일본 — 벚꽃 정원 미로에서 블루나비가 벚꽃잎을 모으고 숨은 친구 사뿐이를 찾아요.

## 짧은 설명 (배너·리플렛 본문용, 2~3문장)
블루나비가 일본 벚꽃 정원 미로를 여행하는 장면이에요. 쓱 밀거나 가고 싶은 칸을 톡 눌러 벚꽃잎 7장을 모으고, 미로 어딘가에 숨은 꽃사슴 사뿐이를 세 번 찾으면 출구 문이 열려요. 물웅덩이와 거미줄, 꽃잎 바람을 피해 에너지를 아끼며 가장 빠르게 도착해 보세요!
