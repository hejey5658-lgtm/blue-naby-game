# 블루나비와 포포의 여행 — 발표 스크립트 (약 1분)

> 발표: 장은영(블루나비) · 「블루나비와 포포의 여행」 · 1탄 세계여행 & 2탄 서울여행 · 장르: 귀여운 여행 퍼즐
> 한글 약 216자 · 1초에 4자, 천천히 · [대괄호]는 화면, 나머지는 소리 내어 읽는 말
> 게임 주소: https://blue-naby-game.web.app · PDF: `docs/presentation/script-1min.pdf` (v5.0.0 내용)

---

**1. 인사** (0:00~0:08) [게임 첫 화면 (썸네일과 같은 화면)]
안녕하세요, 블루나비 장은영입니다. 제가 만든 게임 「블루나비와 포포의 여행」을 소개할게요.

**2. 한마디로** (0:08~0:16) [첫 화면 아래 문구·주소 → 블루나비·포포 톡 → 홈]
설치 없이 링크 하나로 폰에서 바로 하는 귀여운 여행 퍼즐 게임이에요.

**3. 틀린그림** (0:16~0:31) [홈 [1탄 세계여행] → 캐나다 틀린그림 (다른 곳 톡)]
1탄은 블루나비가 중국, 미국, 캐나다를, 2탄은 포포가 봄, 가을, 겨울 서울을 여행해요. 두 그림에서 다른 곳을 다섯, 일곱, 아홉 개씩 톡! 찾아요.

**4. 퐁퐁** (0:31~0:45) [[같이 하기] → 퐁퐁 → 조이스틱으로 겨누고 쏘기 → 사진 완성]
퐁퐁에선 귀여운 조이스틱으로 공을 쏘아 같은 기념품을 모아요. 모일 때마다 조각이 채워져 블루나비와 포포 사진이 완성돼요.

**5. 마무리** (0:45~1:00) [[같이 하기] 화면 → QR]
「같이 하기」로 한 폰에서 번갈아, 또는 각자 폰으로 친구와 겨뤄요. QR을 찍고 지금 바로 함께 여행을 떠나 보세요. 감사합니다!
