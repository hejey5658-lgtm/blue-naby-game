# 블루나비와 포포의 여행 — 발표 스크립트 (약 50초)

> 발표: 장은영(블루나비) · 「블루나비와 포포의 여행」 · 1탄 세계여행 & 2탄 사계절 서울 · 장르: 귀여운 캐주얼 퍼즐 어드벤처
> 한글 약 210자 · 1초에 4자, 천천히 · [대괄호]는 화면, 나머지는 소리 내어 읽는 말
> 게임 주소: https://blue-naby-game.web.app · PDF: `docs/presentation/script-50s.pdf`

---

**1. 인사** (0:00~0:08) [게임 첫 화면 = 썸네일]
안녕하세요, 블루나비 장은영입니다. 제가 만든 게임 「블루나비와 포포의 여행」을 소개할게요.

**2. 한마디로** (0:08~0:17) [첫 화면 아래 문구·주소 → 블루나비·포포 톡 → 홈]
설치 없이 폰에서 바로 하는 귀여운 캐주얼 퍼즐 어드벤처예요. 블루나비와 포포를 톡! 여행을 시작해봐요.

**3. 1탄** (0:17~0:26) [홈의 1탄 세계여행 버튼]
1탄 「세계여행」은 파란 애벌레 블루나비가 배를 타고 중국에서 캐나다까지 네 나라를 여행하며 나비로 자라요.

**4. 2탄** (0:26~0:34) [홈의 2탄 사계절 서울 버튼]
2탄 「사계절 서울」에서는 아기 강아지 포포가 봄, 여름, 가을, 겨울의 서울을 누벼요.

**5. 이렇게 놀아요** (0:34~0:50) [미로(숨은 친구·도구 피리·자전거·비눗방울) → 퐁퐁(망치·폭죽) → 같이 하기 화면]
숨은 친구를 세 번 찾으면 친구가 되고, 피리·자전거·비눗방울 도구가 길을 도와요. 퐁퐁에선 망치로 콩, 폭죽으로 펑! 「같이 하기」로 두세 명이 겨뤄요.
