# 블루나비와 포포의 여행 — 발표 스크립트 (약 50초)

> 발표: 장은영(블루나비) · 「블루나비와 포포의 여행」 · 1탄 세계여행 & 2탄 서울여행 · 장르: 귀여운 여행 퍼즐
> 한글 약 210자 · 1초에 4자, 천천히 · [대괄호]는 화면, 나머지는 소리 내어 읽는 말
> 게임 주소: https://blue-naby-game.web.app · PDF: `docs/presentation/script-50s.pdf`

---

**1. 인사** (0:00~0:08) [게임 첫 화면 = 썸네일]
안녕하세요, 블루나비 장은영입니다. 제가 만든 게임 「블루나비와 포포의 여행」을 소개할게요.

**2. 한마디로** (0:08~0:17) [첫 화면 아래 문구·주소 → 블루나비·포포 톡 → 홈]
설치 없이 폰에서 바로 하는 귀여운 여행 퍼즐 게임이에요. 블루나비와 포포를 톡! 여행을 시작해봐요.

**3. 1탄** (0:17~0:26) [홈의 1탄 세계여행 버튼]
1탄 「세계여행」은 파란 나비 블루나비가 중국, 미국, 캐나다 세 나라를 여행해요.

**4. 2탄** (0:26~0:34) [홈의 2탄 서울여행 버튼]
2탄 「서울여행」에서는 아기 강아지 포포가 봄, 가을, 겨울의 서울을 누벼요.

**5. 이렇게 놀아요** (0:34~0:50) [틀린그림(두 그림·다른 곳 5·7·9개) → 퐁퐁(망치·폭죽) → 같이 하기 화면]
두 그림에서 다른 곳을 다섯, 일곱, 아홉 개씩 톡! 시간 안에 다 찾으면 다음 나라로 떠나요. 퐁퐁에선 망치로 콩, 폭죽으로 펑! 「같이 하기」로 친구와 겨뤄요.
