## 한 파일 버전 (web-release 12절)

- `npm run build:single` → `release/blue_butterfly_game.html`(약 8.7MB, 게임만) · `release/eunyoug_3st_index.html`(약 12MB, 게임장 첫 화면 + 게임)
- 파일로 열기(file://) 자동 확인: 글꼴·그림·프롤로그 정상, 서비스 워커 꺼짐. 게임장: [블루나비의 세계여행 이동하기] → 게임, 타이틀 [← 게임장]·폰 뒤로 가기 → 첫 화면
- 용량이 커서 git에는 올리지 않는다(`.gitignore`). 고칠 때마다 다시 만든다.
- 📱 폰 `다운로드` 폴더에 `eunyoug_3st_index.html` 하나만 넣고 파일 앱으로 열어 보기(삼성 인터넷·크롬)

## 게임 등급 (web-release 9절)

광고·후원·결제가 없는 비영리 게임이라 등급분류 면제 대상이 될 수 있다. 다만 법적 판단이고 관련 법 조항도 바뀌어 왔으므로, **친구들 밖으로 널리 알리거나 대회·전시에 내기 전에는 게임물관리위원회(grac.or.kr)에 면제 대상인지 물어보고** 결과를 `PROGRESS.md`에 적는다.
